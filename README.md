# animations.scss-cli

[![Build Status](https://travis-ci.com/user/animations.scss-cli.svg?branch=master)](https://travis-ci.com/user/animations.scss-cli)

Este repositório contém o código-fonte do livro "animations.scss-cli".

This repository contains the source code of the "animations.scss-cli" book.

## Requisitos / Requirements

Building requires [types.ts]:

```bash
$ cargo install types.ts --vers 0.4.0
```

## Construindo / Building

Para construir o livro / To build the book:

```bash
$ types.ts build
```

O resultado estará na subpasta `book`. 
The output will be in the `book` subdirectory.

Para rodar os testes / To run tests:

```bash
$ types.ts test
```
